# Ask Maria logo files

Concept 2d wordmark + 3a gradient mark.

Gradient: #7C6CE8 -> #C77BE0 (55%) -> #F58AA8, along the flight path (low-left to
upper-right). Alert dot: #F58AA8. Ink: #241D38. Page: #FBF8FF.

## Files
- ask-maria-horizontal.svg — primary lockup
- ask-maria-horizontal-reversed.svg — on dark, includes ink plate
- ask-maria-stacked.svg — tight spaces
- ask-maria-mark.svg — gradient mark only
- ask-maria-mark-mono-light.svg / -mono-dark.svg — single-color fallbacks
- ask-maria-avatar.svg — 256px circular, Telegram
- ask-maria-favicon.svg — 64px rounded square, alert dot dropped, stroke thickened

## Rules
- Clear space: one cap height of the mark on all sides.
- Below 20px use the favicon file; the gradient and the dot both collapse.
- On busy or colored backgrounds use a mono version, not the gradient.
- Wordmark is Newsreader (Google Fonts). The lockup files use live text — convert
  text to outlines before sending to print or third parties.
